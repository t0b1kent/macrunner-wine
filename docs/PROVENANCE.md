# Public source provenance

The first commit is the unmodified `sources/wine` subtree (11,085 files,
Wine 11.0) of the CodeWeavers CrossOver 26.1.0 source release:
https://media.codeweavers.com/pub/crossover/source/crossover-sources-26.1.0.tar.gz

Archive SHA256: `e4ec87d5821a009dd1f1d2e36ffe2e24b8fcbae9516375ea42f95a16928ab8fa`.
`upstream-manifest.tsv` records every upstream file hash. Tag: `crossover-26.1.0`.

MacRunner inputs come exclusively from the published
`MacRunner-1.0.7-S2-sources.tar`, SHA256
`b35d88f3d066fc48dcb76d49675763cf65e64e4abf6954ca3fef3bcaa5cb2416`.
The 383-file published patch was replayed on the base and all 11,255 results
verified against `wine/wine-source-tree-20260929.tar.xz` and the published delta
manifest. Published files were read from the sealed tar, not a live Wine tree.

`release-source-map.json` then records each release-specific replacement,
the precise published member, its SHA256 and the prior tree SHA256. This covers
the five historical floor files, all Wine sources in the accepted 26-input
ntdll map, SIGNED32 WoW64/WoW64Win compiled inputs, selected loader sources,
and the selected cooperative wineserver source. Historical `include/config.h`
is deliberately regenerated by configure rather than installed on a new host.

`third_party/hyperbridge` contains the 78 canonical source/header/include files
of the archived September 7 source snapshot; backup copies were excluded.
Its MIT license is retained from the public HyperBridge project. The selected
signal object used the newer published `hb_probe.h`, which is kept as a
Wine-only include overlay. The library builds from its own original headers.
All Wine compilation sources and Makefiles retain their archived bytes.
The portable recipe stages a copy under the build directory as `source-wine`,
with the required sibling `hyperbridge` source/include/library layout.
The sibling include tree uses the selected Wine-side probe header; the static
library is compiled separately against its own archived vendor headers.
This handles all original forwarding includes and ntdll/win32u/xtajit paths
without rewriting the release source code or placing files outside the checkout.

`published-inputs.json` records the archived input hashes, including both
historical RECOMPILE-CHECK reports. The public build recipes are portable
adaptations of the archived configure command and ARM64EC spike script.
They keep four PE architectures and the original host optimization/deployment
flags, llvm-mingw 20260505 and the native Apple compiler.

`release-1.0.7-sha256.tsv` contains 32 selected file SHA256 values extracted
directly from the published signed/notarized ZIP, SHA256
`ef8ea15b4b03fe136a92b41a9db8f532044a5486372330882141c130eb69b265`.
These are release file hashes, including signing and packaging transformations.
They are not the obsolete September binary hashes in the historical provenance.

Source/hash pairing of retained objects is not proof of recompilation.
See [RECOMPILE-CHECK](RECOMPILE-CHECK.md).
